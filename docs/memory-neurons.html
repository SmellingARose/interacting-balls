Memory neurons

How a network can remember between decisions, explained in three levels, from the idea to the training. Every chart is live: drag the sliders.

Level 1 · the idea

A note to itself

A normal network looks at one photo and acts. A memory neuron also keeps a small note from the last moment and reads it again next time, so the network sees a film instead of a photo.

Level 3 · training

Why they're hard to train

1. Influence explodes or vanishes

An input k steps back reaches today's decision multiplied by U about k times. Below 1 its effect fades to nothing; above 1 it blows up. Training has to land in a narrow band around 1 to remember long without blowing up.

2. A tiny change ripples through every later step

Evolution changes weights by small random amounts. Near U = 1, a small change flips the memory's whole behaviour. Both neurons below get the same single blip; their U differs only by the mutation size. Drag U toward 1.

parent (U)child (U + mutation)

3. Credit is spread over time

A miss at the end may come from a memory written hundreds of steps earlier. Each step in between could be to blame, and evolution only sees the final score.

Level 3 · training

How to train them

The single most useful fix is the leaky neuron. It blends old memory with new input instead of adding them, so it can't blow up. Drag both sliders to compare it with the plain neuron on the same noisy weave.

plain: h = tanh(w·x + U·h)
leaky: h = λ·h + (1−λ)·tanh(w·x) // λ between 0 and 1: always stable

Start U small

U ≈ 0.1

Begin with almost no memory. Evolution grows it only when it helps, and the network stays stable from the first generation.

Leaky or gated neurons

h = g·h + (1−g)·new

A blend instead of a sum can't explode. In gated units (GRU, LSTM) the network learns g itself.

Smaller mutations on U

σU ≈ σ / 5

The memory weights ripple through every step, so nudge them gently while the rest of the network explores.

Curriculum

clean → noise → delay → weave

Learn to hit with perfect sensors first, then add each difficulty once the last one is mastered.
